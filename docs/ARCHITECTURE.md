# MossAgent 架构

[AGENTS.md](../AGENTS.md) 是强制工程约束；本文件说明模块归属和稳定设计边界。
功能状态、详细实施方案与验证限制统一见[功能清单](FEATURE_STATUS_AND_IMPLEMENTATION_PLAN.md)。
整理前的架构增量记录保留在[历史快照](archive/ENGINEERING.md#architecture)，不再并行维护。

## 运行链路

```text
Avalonia View / ViewModel
  -> Application 用例与端口
  -> 每任务独立 Agent runner
  -> 提供商流式请求
  -> 标准工具执行管线
  -> 工具结果 / 文件型产物 / 审计
  -> 任务事件、消息持久化与 UI 投影
  -> 下一轮模型请求
```

UI 负责交互和服务装配；文件、SQLite、HTTP、进程与 Windows API 通过端口进入实现模块。
不引入静态服务定位器或跨任务共享的可变运行状态。

## 模块与依赖

| 模块 | 职责与依赖边界 |
| --- | --- |
| Domain | 实体、值、枚举、纯领域校验；无项目依赖 |
| Tools.Abstractions | 工具描述、请求、上下文和进程/文件会话等契约；仅依赖 Domain |
| Application | 用例、仓储/运行端口、模型能力与调度规则；仅依赖 Domain 和工具契约 |
| Agent | 基于抽象的模型循环、上下文预算、工具/子代理协调；不直接访问 UI、数据库、浏览器或 OS |
| Tools.BuiltIn | 文件、搜索、Shell、Git 等工具及共享执行管线 |
| Providers | OpenAI Responses、Anthropic、Gemini、兼容协议；分离请求、解析、发现与错误映射 |
| Browser | 内外部浏览器、任务会话、标签、导航、下载和产物 |
| MCP | stdio/Streamable HTTP、发现、连接恢复和标准工具适配 |
| Infrastructure | SQLite 向前迁移、仓储、产物、代理/HTTP 和 Git 实现 |
| Platform.Windows | Windows 文件句柄/对象身份、进程树、ConPTY、截图等平台实现 |
| App | Avalonia UI、WebView2、ViewModel、共享控件和 composition root |
| App.Analyzers | 共享视觉组件和外观的编译门禁；无运行时业务职责 |

实现模块不得引用 App。新行为先确定归属、复用端口、安全规则和验证方式，再修改实现。
手写 `.cs` 一文件一类型；文件、方法、AXAML 规模限制以 AGENTS.md 为准。

## 对话、任务与并发

- 任务拥有独立取消令牌、事件流、进程树和浏览器会话。UI 只在 dispatcher 上发布可观察状态，
  长耗时工作不阻塞 UI；关闭页面或任务时解除事件订阅并等待所属资源清理。
- 有项目对话携带授权快照。无项目聊天不隐式获得目录或通用工具权限；显式选择附件只授权
  该快照进入对话，不授予其父目录权限。
- 草稿按 task、项目新对话和无项目范围隔离，带持久化版本检查。发送通过事务同时提交消息
  和消费对应草稿，保留准备期间产生的新输入；失败和取消有明确终态。
- Queue 保存跟进输入及运行配置快照，分派时复核项目/模型/授权；恢复后要求人工继续。
  Steer 在模型边界接收并持久化文本 receipt，保留当前运行模型和权限；附件引导仍有缺口。
- 启动恢复将中断工作标记为中断。恢复历史、浏览器或工具审计不构成重新执行副作用的许可。

## 工具与授权

统一管线顺序如下，内置、MCP、子代理以及 UI 操作入口都必须保留这些边界：

```text
查找 -> schema -> 能力/路径 -> 风险 -> 审批
     -> 超时/取消 -> 执行 -> 输出限制/产物 -> 审计持久化
```

- ReadOnly 拒绝写入、Shell、页面修改及有副作用的 MCP；AskEveryTime 对每个变更、命令、
  浏览器交互及有副作用的 MCP 请求审批；FullAccess 仍受授权根和任务浏览器归属限制。
- 工具不能直接调用另一个工具实现来绕过管线。未知 MCP 默认有副作用；只读声明须来源可信
  且可验证。桌面截图和日常浏览器配置文件访问属于敏感操作。
- 工具上下文支持显式名称范围；注册与调用阶段校验 schema 和参数预算。工具输出有界，
  大结果落文件产物，只向模型上下文传递受预算约束的预览、摘要或分页。
- 审批请求绑定实际任务和动作身份；等待审批、执行、取消、清理及审计保持可查看状态。
  取消返回不能冒充进程已退出或远端副作用已撤回。

详细安全边界及未关闭的竞态见[安全指南](SECURITY.md)。

## 持久化、对象授权与产物

- SQLite 保存结构化元数据、消息、配置、执行与审计；截图、下载、完整日志和二进制放在
  任务产物中，数据库只保留路径、hash、大小及有界预览。变更使用向前迁移，不重释旧数据。
- schema 26 以项目授权 revision 做条件保存并撤销旧租约；跨实例轮询检测变更。
  这是合作取消，尚不构成所有旧资源严格排空的屏障。
- schema 27 将显式项目根 grant 绑定卷和目录文件 ID；schema 28 将工作树 grant 绑定
  task/project 和目录对象身份。旧数据要求明确确认，同路径新目录不自动继承旧授权。
  Windows 生产装配持有目录链，兼容宿主未装配可选端口时不能宣称拥有相同边界。
- 文件读、写、删、复制、同卷移动和产物会话通过平台句柄端口校验实际对象；原子提交、
  外部变更检测和按原句柄清理保留。最终名称条件替换、部分枚举竞态、工作树交接及崩溃回收
  仍有开放项，不应从单个句柄测试推断整类操作完整安全。
- 附件使用不可变、消息/任务所属快照；原始文本/图像在请求前校验模型能力、大小和内容。
  快照缺失或改变时阻止请求并提供恢复指引，不静默切换数据或模型。

## 提供商、模型与代理

- 模型发现和流式请求使用独立 Application 端口；每次请求使用配置中选定的提供商、
  模型、代理及参数。明确直连保持直连，不静默替换失效代理或不可用模型。
- 各协议独立处理推理参数、工具名称映射、续接与终态。解析使用确定性 JSON/SSE 夹具，
  流/错误/输出均有界，异常不得回显凭据或敏感头。
- 上下文预算保留系统指引和完整的近期工具交互，避免截断为非法协议片段。
- 模型能力和自定义思考强度的规则、数据来源与更新方式见[能力数据](MODEL_CAPABILITY_DATA.md)。
  配置项可保存不代表对应媒体传输已经实现。

## 浏览器、MCP、子代理与定时任务

- 浏览器操作显式绑定任务会话和标签，只允许明确配置的 CDP 接入；不扫描任意调试端口。
  内外部浏览器选择、人工接管、下载与截图共用授权、审批、取消和产物边界。
- MCP 配置、发现、执行和恢复通过连接端口和标准工具适配；断开、重连及过期注册可查看。
  MCP server 启动属于代码执行，仍需纳入命令隔离边界。
- 子代理使用保存的提示词、模型、思考强度和上下文共享选项；继承父任务授权，工具重新
  进入标准管线，进度与结果投影到主对话；递归委派不可用。
- 定时任务由 Application 调度/认领端口驱动独立后台 task，保存模型选择、提示词和审批
  策略，不消费前台草稿。目前目录范围取执行时项目授权，完整计划级授权快照尚待实现。
  关闭/崩溃不自动补跑未完成副作用，历史、暂停、手动运行和停止均要保留独立状态。

## Git、工作树与 PR

- Git 状态、差异、暂存、提交、推送和撤销通过受控进程与工具入口执行；预览后复核
  HEAD/索引/远端，保留审批、取消、输出限制及审计，不自动 stage-all、强推或重试。
- 工作树以任务所属目录和选定不可变 commit 为基准；恢复验证目录对象身份和 Git 注册。
  脏或归属不明目录保留供人工核实。创建/清理最终交接与崩溃恢复仍未完整闭合。
- Git hooks、签名和凭据 helper 仍可能执行代码；清理 Git 环境变量不等于 OS 文件隔离。
- 来源账号独立于 AI 提供商。当前 PR 能力是授权后的只读查询和快照审阅，不能当作
  已具备创建、评论、合并等完整写工作流。

## UI 与验证

业务视图使用 `MossAgent.App.Controls` 包装组件，通过 `Classes` 选择集中样式。
仅布局/模板原语可直接使用原生元素；页面不覆写组件外观、模板或实例尺寸来绕过共享规则。
构建门禁、MOSSUI001/002 和组件测试共同约束 AXAML 与 C#。具体目录与示例见[组件指南](UI_COMPONENTS.md)。

界面验收关注真实入口、焦点/键盘、禁用/加载/空/错误、明暗和主要窗口尺寸；
截图用于发现遮挡、裁切与可读性问题。Headless、模拟服务、真实本地资源、原生 GUI、
真实账号与单文件包分别记录证据。正常构建/发布坚持 JIT、Windows x64 自包含单文件，
不启用 AOT 或裁剪；操作命令见[项目说明](../README.md)。
