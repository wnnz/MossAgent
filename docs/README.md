## 维护方式

- 功能变化先更新功能清单对应的 C/R 项，写清入口、真实运行链路、证据类型和剩余范围。
- 架构、组件或安全规则变化时再更新相应指南；不再新增同一状态的平行矩阵或逐按钮报告。
- 历史归档保留原检查点。新证据在功能清单或相关指南集中记录版本、命令、结果和产物位置；
  只有需要保留独立实验原文时才追加到相应主题归档。
- 自动化、模拟服务、Headless、原生 GUI、真实账号及发布包分别记证据；旧截图不构成像素复刻要求。
- 不将密钥、代理凭据、授权头或 Cookie 写入文档及诊断产物。
